# 競馬予想AI Cloud Ver.1.7.1

## 確定払戻・回収率自動集計版

Ver.1.7に、レース前買い目の固定保存とJRA確定払戻による回収率を追加しました。

### 自動処理
- 朝予想を保存
- 発走15～65分前の予想を保存
- その時点の買い目も同時保存
- レース終了後に着順とJRA払戻金を取得
- 的中 / 不的中 / 返還を買い目単位で判定
- 購入額・払戻額・収支・回収率を自動計算
- レース別・日別・券種別・累計回収率を表示

### 自動買い目の初期値
- 買い方：標準
- 予算：1レース 2,000円

`.github/workflows/keiba_auto_predictions.yml` の
`KEIBA_BET_STYLE` と `KEIBA_BET_BUDGET` で変更できます。

### 対応券種
- 単勝
- 複勝
- 馬連
- ワイド
- 三連複

### 返還
JRA結果ページに返還馬番がある場合、その馬を含む保存済み買い目は
購入額を返還額として計上します。

### 評価優先順位
同じレースに複数予想がある場合は、
1. pre_race
2. morning
3. manual
の順で評価します。二重計上はしません。

### Ver.1.7で既に作成した朝予想
旧CSVはそのまま使えます。
買い目列が空の既存朝予想は、保存済み予想データだけから買い目を補完します。
結果データは買い目作成に使いません。
