# 競馬予想AI Cloud Ver.1.5

Cloud Ver.1.4に「当日コンディション」を追加した版です。

## Ver.1.5の追加機能

- JRA公式の当日馬場状態（良・稍重・重・不良）
- JRA公式の含水率
- JRA公式のクッション値（ページから安全に取得できる場合のみ）
- JRA公式の使用コース・芝状態
- Open-Meteoの当日天気、気温、降水、降水確率、風
- 最新の馬体重・馬体重増減
- 最新の単勝オッズ・人気
- 終了済みの同条件レースから当日の内外傾向を算出
- 終了済みの同条件レースから前有利／差し有利傾向を算出
- 全頭ごとの「基礎AI指数」「当日補正」「補正理由」を表示

## 予想への反映方法

### AI本体へ直接反映
- 馬場状態 going
- 馬体重
- 馬体重増減
- 単勝オッズ
- 人気

これらは学習済みAIが元から使用している特徴量です。

### 当日補正として反映
- その馬の当該馬場状態での過去3着内率
- 含水率／クッション値による湿潤度の補助情報
- 当日の内外傾向
- 当日の前有利／差し有利傾向

当日補正は最大±5ポイントに制限し、
馬ごとに補正理由を画面へ表示します。

## データの扱い

JRA公式馬場情報が予想日と一致しない場合は、
古い馬場状態をAIへ上書きしません。

クッション値はJRAページ上で安全に数値を特定できる場合のみ使用し、
基準表の「12・10・8・7」を誤って実測値として扱わない設計です。

## GitHub / Streamlit Cloud更新

既存の `keiba-ai-cloud` リポジトリへVer.1.5のファイルを上書きすれば、
Streamlit Community Cloudは通常、自動で再デプロイします。
