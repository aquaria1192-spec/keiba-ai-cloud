# 競馬予想AI Cloud Ver.1.9.1

## Ver.1.9 NameError 修正版

Ver.1.9で、Streamlit起動直後など当日データがまだ読み込まれていない状態で
`day` を参照し、NameErrorになる問題を修正しました。

### 修正内容

- `day` を必ず空DataFrameとして初期化
- 当日データ未取得時は一括予想処理へ入らない
- 「最新データに更新」を押す案内を表示
- 開催地が0件の場合の安全処理を追加
- レースが0件の場合の安全処理を追加

### Ver.1.9の機能はそのまま

- 開催地を選択
- 開催地の全レースを一括予想
- 全レース一覧を表示
- レース選択で該当レース詳細へ切替
- レース切替時はAI再計算なし
