# 競馬予想AI Cloud Ver.1.11

## 精度強化モデル

Ver.1.11は、補正を増やすのではなく、2016-2023を学習期間、2024・2025を別期間として確認し、改善が確認できた変更を反映しています。

### 主な変更

- ◎本命順位を旧AI指数順から **勝率モデル優先** へ変更
- 馬の当該馬場状態適性をAI本体へ追加
- 騎手×競馬場 / 芝ダート / 距離 / 馬場 / 調教師をAI本体へ追加
- 調教師×競馬場 / 芝ダート / 距離をAI本体へ追加
- レース内の相対評価（市場順位、近走成績、騎手成績、調教師成績など）を追加
- 騎手名・調教師名そのものをHistGBの序数カテゴリから外し、条件別の実績値で評価
- AI本体で学習した馬場適性・騎手条件適性を当日補正で二重加点しない
- 当日終了レースから得る内外・脚質傾向・当日騎手成績は引き続き小幅補正

### 時系列ホールドアウト確認

| 指標 | 旧方式 | Ver.1.11 |
|---|---:|---:|
| 2024 本命1着率 | 34.93% | 36.10% |
| 2024 本命3着内率 | 66.28% | 67.18% |
| 2025 本命1着率 | 35.06% | 36.97% |
| 2025 本命3着内率 | 66.77% | 67.56% |

2025の本命1着率では、旧方式35.06%からVer.1.11では36.97%でした。
これは過去データでの検証結果で、将来の成績を保証するものではありません。

### 日付データの注意

元の2016-2025学習データは `sequence_proxy` 日付です。年単位の時系列分離には使用していますが、`days_since_last` は厳密な実日数ではありません。真の日付へ置き換えられれば、さらに改善余地があります。

### 一括予想・答え合わせ

Ver.1.10の仕組みを継承し、開催地全レース一括予想を答え合わせ用に固定保存します。レース詳細の選択は答え合わせ基準を変更しません。
