# 競馬予想AI Cloud Ver.1.8.1

## JRA当日馬場取得 修正版

Ver.1.8で馬場状態が「-」になる場合がある問題を修正しました。

### 原因
JRA公式ページはHTTPヘッダーの文字コード情報だけでは正しく判定できない場合があり、
Python requests の `response.text` に任せると
「天候」「芝」「稍重」などの日本語が文字化けして、
当日馬場パーサーが値を見つけられない場合がありました。

また、12レース分のJRA公式URL一覧を収集できなかった場合、
当日出馬表の馬場情報まで取得しない経路がありました。

### 修正
- JRAレスポンスの生バイトを使用
- CP932 / Shift-JIS / UTF-8 を比較して最適な日本語デコードを選択
- `芝稍重` / `芝：稍重` の両形式を認識
- JRA公式URL一覧の収集に失敗しても、当日公式シードページを直接取得
- 中山・阪神それぞれ1つの公式出馬表からコースの現在馬場を取得
- JRA公式補完出走表も同じ文字コード修正を適用
- アプリに「JRA公式当日出馬表から取得成功」の表示を追加
- 失敗時は「馬場取得診断」に理由を表示

### 2026年9月27日の確認対象
JRA公式出馬表上では、
- 中山：天候 曇 / 芝 稍重
- 阪神：天候 曇 / 芝 良
が表示されています。
