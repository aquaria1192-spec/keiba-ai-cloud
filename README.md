# 競馬予想AI Cloud Ver.1.8

## 騎手・当日馬場 強化版

### 馬場状態取得を強化
Ver.1.8では馬場状態の取得順を次のようにしました。

1. JRA公式出馬表の当日表示（最優先）
2. JRA馬場情報ページ
3. 取得済み当日出走表の馬場状態（週間ページが古い場合は上書き）

JRA公式出馬表には当日の「天候」「芝/ダートの馬場状態」が表示されるため、
週間馬場情報側の「金曜正午現在」など古い状態を誤って優先しないようにしています。

含水率・クッション値・使用コース・芝状態はJRA馬場情報ページから取得できた値を表示します。
安全に現在値を特定できないクッション値は推測せず空欄にします。

### 騎手データを強化
学習済みAIは従来から騎手名と騎手3着内率を特徴量として使用しています。
Ver.1.8ではさらに2016-2025の学習履歴から、

- 騎手×競馬場
- 騎手×芝/ダート
- 騎手×距離帯
- 騎手×馬場状態
- 騎手×調教師

の3着内率と騎乗数を追加しました。

これらは全体騎手成績との差だけを小幅な「騎手補正」として使うため、
AI本体にすでに入っている騎手評価を二重計上しにくい設計です。

さらに、同じ開催日の終了済みレースから、その騎手の当日騎乗成績も取得し、
サンプル数に応じて弱く補正します。

### 画面表示
全頭予想表に次を追加しました。

- 騎手
- 騎手過去3着内率
- 騎手補正
- 騎手評価理由

### 注意
新しい騎手補正や馬場取得方式が実戦精度を上げるかは、今後の答え合わせで検証します。
補正は最大幅を抑え、元の学習済みAIを大きく上書きしない設計です。
