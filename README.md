# 競馬予想AI Cloud Ver.1.9.2

## `1R` レース番号変換エラー修正版

Ver.1.9.1で当日データ取得時に

`invalid literal for int() with base 10: '1R'`

となる問題を修正しました。

### 原因

取得した出走表のレース番号は `1R`, `2R` のような文字列ですが、
当日馬場取得用のデータを作る際、一部で `int("1R")` としていました。

### 修正

レース番号を次の形式すべてで扱えるよう統一しました。

- `1`
- `01`
- `1R`
- `01R`

内部では安全に数値 `1` へ変換してから使用します。

修正箇所:
- 当日馬場取得へ渡すレース番号
- 公開出馬表フォールバック
- 当日バイアス取得
- JRAレースID照合

Ver.1.9の開催地ごと全レース一括予想機能はそのままです。
