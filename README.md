# 競馬予想AI Cloud Ver.1.4

PCを起動しておく必要がないクラウド専用版です。

主な機能:
- スマホ / PCのブラウザから利用
- 出走データ自動取得
- 開催地 → レース選択
- 全出走馬の印付き予想
- 勝率 / 3着内率 / AI指数 / 単勝オッズ / AI期待値
- 堅実 / 標準 / 攻め の馬券提案
- 1レース予算に応じた100円単位の買い目
- 最新データ再取得

クラウド軽量化:
- 464,232走の学習CSVを毎回読み込まない
- 学習済みAIを同梱
- 過去成績は集約済み特徴量ストアを使用

公開手順は `CLOUD_DEPLOY手順.md` を参照してください。
