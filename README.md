# 競馬予想AI Cloud Ver.1.9

## 開催地ごと全レース一括予想版

Ver.1.9では、従来の

`開催地 → レース選択 → 1レース予想`

を変更し、

`開催地選択 → 開催地の全レース一括予想 → レース選択 → 詳細表示`

にしました。

### 動作

中山を選択すると、中山のAI予想対象レースをまとめて計算します。

阪神へ切り替えると、阪神の全レースをまとめて計算します。

一度計算した開催地はセッション内に保持するため、
1R → 5R → 11R のようにレースを切り替えても
AI本体の再計算は行いません。

### 全レース一覧

開催地を選ぶと、まず全レースの一覧を表示します。

一覧には主に以下を表示します。

- レース番号
- レース名
- 馬場
- ◎本命馬
- 本命馬の騎手
- 勝率
- 3着内率
- AI指数
- 単勝オッズ
- AI上位差
- 当日傾向

### レース選択

全レース一覧の下に「詳細を見るレース」を追加しました。

レースを選択すると、下の詳細表示がそのレースへ切り替わります。

予想はすでに開催地単位で計算済みなので、
レース選択のたびに再予想しません。

### 当日データ更新

「最新データに更新」を押した場合は、
開催地一括予想のキャッシュを破棄して、
新しいオッズ・馬体重・馬場状態で全レースを再予想します。

### 当日補正

「当日馬場・バイアス補正を反映」を切り替えた場合も、
開催地全レースをその設定で再計算します。
