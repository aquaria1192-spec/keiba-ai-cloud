# 競馬予想AI Cloud Ver.1.8.2

## 当日馬場 3段階取得版

Ver.1.8.1でもStreamlit CloudからJRA公式ページへの直接アクセスが
失敗する環境があったため、馬場取得を3段階にしました。

### 取得優先順位

1. JRA公式当日出馬表
2. 取得済みの当日出走表
3. 公開出馬表の当日レースヘッダー

最終的に同日の現在値が取れれば、
AIの `going` 特徴量へ反映します。

### 重要な修正

公開出馬表では稍重が `馬場:稍` と表示される場合があります。
旧版は `稍重` の文字列だけを探していたため、値を取りこぼしていました。

Ver.1.8.2では

`稍` → `稍重`

へ正規化します。

またJRA公式HTMLで `芝�c重` のように文字化けした場合も
`稍重` として安全に認識します。

### 画面表示

- JRA直接取得成功
  `JRA公式当日出馬表から現在の馬場・天候を取得できています。`

- JRA直接取得失敗、代替取得成功
  `同日の公開出馬表から現在の馬場・天候を取得できています。`

- 全取得失敗
  `現在の馬場状態を取得できていません。`

### 2026-09-27確認例

公開出馬表では
- 中山11R 芝：馬場 `稍`
- 中山6R ダート：馬場 `稍`

と表示されます。
アプリ内部では両方とも `稍重` に変換します。
