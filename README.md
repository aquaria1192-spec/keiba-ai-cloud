# 競馬予想AI Cloud Ver.1.12

## Ver.1.12 の位置づけ

Ver.1.10 を安全な比較基準として、2016〜2025 の既存大規模CSV（464,232行・33,244レース）から特徴量を再生成し、2016〜2023で学習、2024で確率校正、2025を未使用の最終ホールドアウトとして再検証した版です。

既存CSVの日付はすべて `sequence_proxy` です。年単位の過去→未来分離には使いますが、実際の日付間隔としては扱いません。今後のレースは `true_date` として別管理します。

## 出走データの永続保存

一度取得した当日出走データは、Streamlitのセッションだけでなく履歴専用GitHubリポジトリへ日付別CSVとして保存します。アプリ終了・再起動後は同じ開催日を選ぶと保存済みデータを自動復元し、「最新データに更新」を押したときだけネット取得で上書きします。

## 精度強化

Ver.1.11 相当の特徴量強化を再構築したうえで、確率予測を追加校正しました。

- ◎本命順位は勝率モデルを主軸に判定
- 馬×馬場状態の適性
- 騎手×競馬場 / 芝ダート / 距離 / 馬場 / 調教師
- 調教師×競馬場 / 芝ダート / 距離
- レース内相対評価（市場順位、近走、騎手、調教師など）
- 当日終了レースの内外・脚質・当日騎手成績は小幅補正
- HistGB単独構成では、2024だけで固定した確率校正を適用
- 2025は校正値の決定に使用せず、最終ホールドアウトとして評価

## 開催地一括予想と答え合わせ

Ver.1.10 の運用フローを維持します。

1. 開催地を選択すると全対象レースを一括予想
2. 予想結果を `course_batch` として固定保存
3. レース選択は表示切替だけで、AIを再計算しない
4. レース後は固定済み予想とJRA確定着順を照合
5. ◎単勝的中率・◎2着率・◎3着内率・印別成績・確率精度を集計

結果を見た後で予想値を作り直し、事前予想として評価することは禁止します。

## true-date 自動学習

Ver.1.12 は確定した新規レースを学習データとして蓄積します。

- Streamlitの開催地一括予想時に、答え合わせ用予想と同時にレース前特徴量を固定保存
- 「この日の全レースをまとめて答え合わせ」で確定着順を予想履歴へ永続保存
- 保存直後に同じ着順を学習用特徴量へラベル付けし、保存後の再読込確認も行う
- 答え合わせ直後に champion / challenger の評価条件を自動確認
- 新しい確定レースが200レース以上増えた時だけ challenger を作成
- 過去→未来の時系列分割で champion と比較
- Win / Top3 の Log Loss・Brier と Calibration を主指標に採用判定
- 条件を満たした場合だけオンライン補正モデルを昇格
- 馬券の買い目・回収率は評価対象にせず、予測精度指標だけでモデルを比較する

Streamlitで固定した学習データ・答え合わせ結果・オンライン補正モデルは、予想履歴と同じ `GITHUB_HISTORY_REPO` に永続保存します。GitHub Actionsの自動レース前予想は従来どおり `prediction-history` ブランチを使用します。アプリは自身の答え合わせから昇格した補正モデルを優先し、存在しない場合だけ公開済み自動学習モデルへフォールバックします。基準の `cloud_model.joblib` は自動上書きしません。

詳しい安全設計は `ONLINE_LEARNING.md` を参照してください。
