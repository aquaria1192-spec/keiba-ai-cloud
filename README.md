# 競馬予想AI Cloud Ver.1.10

## 開催地一括予想をそのまま答え合わせする版

Ver.1.9系では開催地の全レースを一括予想しても、評価履歴に保存されるのは
画面で詳細表示したレースだけでした。

Ver.1.10では、開催地を選択して全レース予想が完成した時点で、
その開催地の全レースを答え合わせ用としてまとめて固定保存します。

### 流れ

1. 当日データを取得
2. 開催地を選択
3. 開催地の全レースを一括予想
4. 全レースの予想・印・確率・AI指数・買い目を固定保存
5. レース選択は表示切替だけ
6. 結果公開後、一括予想を基準に答え合わせ
7. 回収率も一括予想時の買い目で計算

### 答え合わせの優先順位

1. `course_batch` 開催地一括予想
2. `pre_race` GitHub Actions発走前予想
3. `morning` 朝予想
4. `manual` 旧手動予想

一括予想が保存されているレースでは、他の予想を答え合わせに使用しません。

### 買い目

一括予想の答え合わせ条件を統一するため、現在は

- 買い方：標準
- 1レース予算：2,000円

で全レースの買い目を一括予想時に固定保存します。

### 重要

レース詳細を後から1R、5R、11Rと切り替えても、答え合わせ用予想は変わりません。
詳細画面は保存済み一括予想の表示用です。
